**Resolution:** Routed to Step 4; Nestor selected "fix the rename now." On closer inspection while attempting the fix, `architecture.md` does **not** currently have stale terminology to rename — it consistently and correctly uses "secret" only for the generic encrypted-value/crypto concept (`SecretValue`, `packages/crypto`, "a secret value", "secret record") and "credential" for the product's domain entity throughout (`credentials`/`credential_versions` tables, "Credential fetch", `AuditEvent.CREDENTIAL_VALUE_REVEALED`, `/credentials` UI routes) — confirmed via a full re-grep of every `secret`-adjacent line in the current doc. The finding accurately described a real Epic 2-era problem, but the underlying issue appears to have already been resolved at some point between Epic 4 and now without a retro ever confirming/closing it on record — this session is that confirmation. No rename performed; performing one now would have introduced unnecessary, potentially harmful churn against a currently-consistent document.
